# Installation

## I. Téléchargement des fichiers

Pour commencer, vous devez télécharger les fichiers nécessaires du module **hbkcolissimochrono**. Vous pouvez le faire facilement via Composer en exécutant la commande suivante dans votre terminal :

```bash
composer require habeuk/hbkcolissimochrono
```

Cette commande va télécharger le module et toutes ses dépendances dans votre projet Drupal.

## II. Activation du module

Une fois les fichiers téléchargés, vous avez deux options pour activer le module :

Via Drush
Si vous utilisez Drush, l'outil en ligne de commande pour Drupal, activez le module en exécutant :

```bash
vendor/bin/drush en hbkcolissimochrono -y
```

Via l'interface graphique
Pour activer le module via l'interface graphique de Drupal :

1.  Connectez-vous à l'administration de votre site Drupal.
2.  Naviguez jusqu'àExtenddans le menu principal.
3.  Recherchez **hbkcolissimochrono** dans la liste des modules disponibles.
4.  Cochez la case à côté du module.
5.  Cliquez sur le boutonInstallen bas de la page pour activer le module.
